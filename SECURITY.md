# Security Policy

## Scope

CapsAwake is a local macOS utility. It is designed to work without accounts, telemetry, analytics, or required network access.

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Use the private contact method listed in the repository profile or contact the maintainers directly with reproduction steps, affected versions, and impact.

Please do not include personal paths, hostnames, tokens, or other sensitive data in reports.

## Supported versions

Security support begins with the first public release. The supported-version policy will be updated when release versioning is established.
