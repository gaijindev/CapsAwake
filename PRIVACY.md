# Privacy

CapsAwake is designed to be auditable and quiet.

- It reads the Mac's logical Caps Lock modifier state. It does not record keystrokes.
- It does not request Accessibility or Input Monitoring permission.
- It does not collect analytics, telemetry, advertising identifiers, account data, or usage history.
- Configuration stays in the user's local Application Support folder. JSON export is always user initiated.
- Notifications are optional and are enabled only after the user asks for them.
- The app has no required network connection. Release downloads and Homebrew are outside the running app.

If you find a privacy or security issue, follow the reporting guidance in [SECURITY.md](SECURITY.md).
